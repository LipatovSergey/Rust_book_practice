# Определение enum

`enum`(перечисление) позволяет создавать тип который имеет несколько возможных вариантов, каждый вариант хранит свои данные, но при этом всё это один тип.

```rust
enum IpAddrKind {
    V4,
    V6,
}

fn main() {
    let four = IpAddrKind::V4;
    let six = IpAddrKind::V6;

    route(IpAddrKind::V4);
    route(IpAddrKind::V6);
}

fn route(ip_kind: IpAddrKind) {}
```

До меня тут долго не доходило, что вообще такое в этом варианте реализации `V4` и `V6`. Если сделать вывод в консоль `ip_kind` то получим `V4` или `V6`. Самая близкая аналогия это `bool` с его `true`, `false`. `true` и `false` это просто варианты(возможные состояния) типа `bool` они не хранят никакие данные в себе.

Но помещать данные непосредственно в любой из вариантов возможно. Например

```rust
fn main() {
    enum IpAddr {
        V4(String),
        V6(String),
    }

    let home = IpAddr::V4(String::from("127.0.0.1"));
    let loopback = IpAddr::V6(String::from("::1"));
}
```

Каждый вариант перечисления становиться функцией, которая создаёт экземпляр перечисления. То есть `IpAddr::V4()` это вызов функции, которая принимает значение с типом String и возвращает экземпляр типа `IpAddr`. Важно! Вариант перечисления становиться такой функцией только если указано, какое значение он принимает. Если варианты определены как в первом примере, они не являются функцией.

Варианты enum могут принимать любые корректные для Rust типы данных.Включая структуры и даже другие перечисления. Например:

```rust
fn main() {
    enum IpAddr {
        V4(u8, u8, u8, u8),
        V6(String),
    }

    enum Message {
        Quit,
        Move { x: i32, y: i32 },
        Write(String),
        ChangeColor(i32, i32, i32),
    }
}
```

Забегая вперёд немного про память. Enum это tagged union он хранит дискриминант и данные выбранного типа. В памяти он занимает размер самого большого варианта + немного на дискриминант.

Для `enum` как и для структур можно определять методы.

```rust
impl Message {
  fn call(&self) {
      // method body would be defined here
  }
}

let m = Message::Write(String::from("hello"));
m.call();
```

Важно! Так как разные варианты могут принимать разные типы данных, в методах обычно применяют match чтобы обрабатывать разные варианты. То есть логика внутри метода, должна корректно работать со всеми возможными вариантами.
