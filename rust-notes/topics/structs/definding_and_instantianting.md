# Определение и создание экземпляров структур

Структуры как и кортежи предназначены для хранения данных, части структур могут быть разных типов. В структуре для хранения и доступу к полям используются ключи. Отдалённо это напоминает `JS` объект. Хотя по принципу работы структуры напоминают больше классы. Далее будет видно почему.

_Каждая структура это отдельный тип!!!_

Ключевое слово `struct` позволяет определить структуру

```rust
struct User {
    active: bool,
    username: String,
    email: String,
    sign_in_count: u64,
}
```

После определения структуры можно создавать её экземпляры.

```rust
fn main() {
    let user1 = User {
        active: true,
        username: String::from("someusername123"),
        email: String::from("someone@example.com"),
        sign_in_count: 1,
    };
}
```

Также можно создавать mutable экземпляры. Важно, что изменяемым может быть только весь экземпляр целиком. Нельзя сделать изменяемым только одно конкретное поле

```rust
fn main() {
    let mut user1 = User {
        active: true,
        username: String::from("someusername123"),
        email: String::from("someone@example.com"),
        sign_in_count: 1,
    };

    user1.email = String::from("anotheremail@example.com");
}
```

### Сокращённая инициализация поля

Далее приводиться пример функции которая принимает значения через аргументы и потом создает и возвращает экземпляр структуры User. Этот пример нужен чтобы показать как использовать сокращённую инициализацию полей знакомую мне из `JS`. Нужно использовать одинаковые называния для аргументов и для полей и тогда можно использовать краткую запись.

```rust
fn build_user(email: String, username: String) -> User {
    User {
        active: true,
        username: username,
        email: email,
        sign_in_count: 1,
    }
}

fn build_user(email: String, username: String) -> User {
    User {
        active: true,
        username,
        email,
        sign_in_count: 1,
    }
}
```

### Создание экземпляра на основе другого экземпляра той же структуры.

Тут объясняется как использовать синтаксис похожий на spread operator. В примере показано что делать если необходимо создать новый экземпляр на основе другого, но при этом изменить значения для одного из полей.

В этом примере важно обратить внимание на то как работает ownership. После определения `user2`. Мы теряем доступ к полю `user1.username` так как String не `Copy` тип и владение им передастся в `user2.username`. Но при этом `user1.active` и `user1.sign_in_count` всё ещё будут доступны так как имеют `Copy` тип.

```rust
fn main() {
    // --snip--

    let user1 = User {
        email: String::from("someone@example.com"),
        username: String::from("someusername123"),
        active: true,
        sign_in_count: 1,
    };

    let user2 = User {
        active: user1.active,
        username: user1.username,
        email: String::from("another@example.com"),
        sign_in_count: user1.sign_in_count,
    };

    let user3 = User {
        email: String::from("another@example.com"),
        ..user1
    };
}
```

### Кортежные структуры.

Через структуры можно создавать структуры похожие на кортежи. Имена для полей им не нужны. Для доступа к значению поля используется `.index`.
Важная особенность. Каждая структура имеет свой собственный тип. Естественно кортежи с одинаковыми значениями но с разными типами это разные кортежи. То есть если функция принимает Color передать в неё origin нельзя хоть типы данных и там и там одинаковые.

```rust
    struct Color(i32, i32, i32);
    struct Point(i32, i32, i32);

    let black = Color(0, 0, 0);
    let origin = Point(0, 0, 0);

```
