# Определение методов

На базовом уровне описанном в уроке похожи на методы классов из других языков. Определяются в контексте структуры. Имеют доступ к самому себе через `self` аналог `this` из `JS`. На этом сходства заканчиваются.
Определяются методы через ключевое слово `impl` (implementation).

```rust
fn main() {
    example_1();
}

fn example_1() {
    #[derive(Debug)]
    struct Rectangle {
        width: u32,
        height: u32,
    }

    impl Rectangle {
        fn area(&self) -> u32 {
            self.width * self.height
        }
    }

    let rect1 = Rectangle {
        width: 30,
        height: 50,
    };

    println!(
        "The area of the rectangle is {} square pixels",
        rect1.area()
    );
}
```

Правила владения для методов такие-же как и везде. Поэтому `&self` нужно обязательно передавать через ссылку. Это специальное сокращение, которое допускает Rust из-за того, что `self` используется очень часто. На самом деле это `self: &Self`. Соответственно если бы было необходимо изменять экземпляр, на котором вызывается метод силами самого метода нужно использовать `&mut self`. Методы которые берут экземпляр во владение встречаются редко, но всё же допустимы, обычно используется, когда нужно превратить `self` во что-то ещё и при этом запретить вызывающей стороне доступ к исходному экземпляру.

Методам можно давать те же имена, что и полям структуры. Чаще всего (но не всегда) такой подходи используется для создания геттеров. Делаем само поле приватным а его значение вызывающий может получить через такой геттер метод.

### Разбор сноски из статьи "Где используется оператор ->"

Про часть о C и C++ можно забить. Главная мысль тут в том, что Rust автоматически передаёт экземпляр в метод в том виде в котором он описан в методе и это не нужно указывать в ручную. То есть если метод использует `&self`, то при вызове этого метода просто указывается `rect1.area()` Rust сам определяет что нужно в метод area передавать `rect1`, как ссылку и не нужно писать `(&rect1).area()`. Также если бы в метод использовался для изменения экземпляра, то Rust автоматически подставлял бы `(&mut rect1).area()`.

### Методы с несколькими параметрами

Ничего особенно нового тут не объяснили. Самое важное `self` всегда идёт первым параметром. Всё остальное по обычным правилам.

### Ассоциированные функции

Они в этом уроке тоже затрагиваются только вскользь но вот, что я уже смог понять. Так называют методы которые не используют self. Чаще всего их используют, как конструкторы. Они привязаны к типу, но не привязаны к `self`. Из примера довольно понятен принцип их работы.

```rust
impl Rectangle {
    fn square(size: u32) -> Self {
        Self {
            width: size,
            height: size,
        }
    }
}
```

Этот метод возвращает новый экземпляр Rectangle. Вызываются такие ассоциированные функции через `::`.
`let sq = Rectangle::square(3)`
