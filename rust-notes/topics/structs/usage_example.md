# Пример использования Struct

В этом разделе 5.2 ничего особенного интересного про сам Struct не было. Просто показали пример, что когда в функцию передаются взаимосвязанные аргументы лучше всего использовать для этого Struct. В целом я пришёл уже к такому выводу самостоятельно когда работал над express приложением. Если метод сервиса ожидает например user.id и user.email лучше всего описать отдельный тип объекта и потом передавать все необходимые аргументы в одном объекте этого типа.

Но в конце урока была полезная информация об использовании `println!` и `dbg!`. Если вкратце, в Rust примитивные типы уже имеют встроенный Display, благодаря тому, что у них есть единственный и конкретный вид в котором они будут выведены. Для типов созданных через структуры, Display и Debug нет но умолчанию потому, что может быть несколько вариантов того в каком виде их нужно вывести. Поэтому нужно добавлять атрибут `#[derive(Debug)]`. Для `println!` можно вывести значения через `{:?}` или через `{:#?}` они дают немного разный стиль вывода.

Важно! Разница между `println!`и `dbg!`.
`println!`
По умолчанию использует ссылки. Поэтому никаких проблем с наследованием не возникает. Вывод всегда в `stdout`.

`dbg!`
Выводит также дополнительную информация о том где он был вызван и т.п. Поэтому он становиться владельцем значения которое ему передаётся. Поэтому нужно следить за тем что в него передаётся ссылка.

Все примеры из этого раздела можно запустить через

```bush
cargo run --example struct_usage_example
```
